# Azure Hand book

An interactive Azure learning handbook that brings theory, portal walkthroughs, concept explanations, and self-assessment into one reading experience.

## Features

- **27 learning chapters** covering Azure fundamentals, hosting, networking, databases, security, deployment, monitoring, and recovery.
- **Separate Theory, Practice, and Test tabs** to keep learning focused.
- **English, Hindi, and Hinglish reading options**, with two languages displayed together.
- **Clickable concepts and diagrams** that open explanations without leaving the chapter.
- **81 scenario-based questions** and a randomized 20-question mixed exam.
- **Scores, answer explanations, and retry options** for self-evaluation.
- **293 reference entries** for exploring additional services and concepts.
- **Comfortable reading controls**, including adjustable font size, focus mode, full-page view, and fullscreen.
- **Local progress tracking** with chapter progress export and import.

## Getting Started

Download the HTML file and open it in a modern browser. No installation or build step is required.

Choose a chapter, select your reading language, and move between:

1. **Theory** — understand the concept and its role.
2. **Practice** — follow the Azure Portal steps and verify the result.
3. **Test** — evaluate your understanding and review explanations.

## Language Coverage

All 27 chapters include Hindi theory alongside English and Hinglish. Translation coverage varies for quizzes, practical instructions, and reference entries.

## Progress and Privacy

Reading progress, assessment scores, and notes are stored locally in your browser. They do not automatically sync between devices.

The handbook does not sign in to Azure or create, modify, or delete cloud resources.

## Practical Guidance

The illustrations explain concepts and portal layouts; they are not live Azure screenshots. Actual practice requires an Azure account.

Check the selected pricing tier, subscription offer, permissions, and resource dependencies before deploying. Azure interfaces, availability, and pricing can change.

## Scope

This is an independent educational handbook. The reference catalog includes services, resource types, features, and portal tools; not every entry has a dedicated practical lab.
